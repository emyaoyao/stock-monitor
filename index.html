多设备共享（填一次，各设备共用同一份清单）
① GitHub 共享令牌（推荐）：每台设备填同一个令牌，即共用同一份清单—— 手机加的票，电脑上立刻能看到，反之亦然。
令牌只存在本机浏览器，除 GitHub 外不会发往任何服务器。
在另一台设备打开这个链接即自动完成配置（链接内含令牌，请不要发到群里或公开场合）。
如何创建令牌（约 2 分钟，只需这一次）：
① 点这里打开创建页
② Repository access 选 Only select repositories，只勾 stock-monitor
③ Permissions → Repository permissions：Contents 设为 Read and write、Actions 设为 Read and write
④ Generate token → 复制 → 粘贴到上面输入框保存
② 云函数代理（可选）：部署了云函数后填地址和口令，手机端就不必保存令牌，只带口令即可。 还没部署就留空，用上面的方式 ① 就够。
不配置也能查看清单和信号；配置后可在 APP 内直接增删并触发云端扫描。 都不填时「添加/移除」会跳到 GitHub Actions 网页操作。
